Hello Bootstrap!

Bootstrap is a CSS framework that helps to create websites faster and more easily. It was created in 2010 by twitter developers Mark Otto and Jacob Thornton. It was initially called Twitter Blueprint. Later, in 2011, it was released publicaly as Bootstrap. It gives ready-made:- Buttons, Navbar, Cards, Forms, Grids, Responsive layouts, Modals etc.
